# Security policy

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public issues,
discussions, or pull requests.

Report them privately using this repository's
[GitHub private vulnerability reporting](https://github.com/eshenhu/someip_proto/security/advisories/new)
form. Include a clear description, affected versions or commits, reproduction
steps, and impact where available.

Maintainers will acknowledge a report, assess it privately, and coordinate a
fix and disclosure timeline with the reporter. The repository must enable
private vulnerability reporting before its public release; see
[`docs/repository-settings.md`](docs/repository-settings.md).

## Supported versions

Until the first public release, only the default branch is supported. The
project's first planned release is experimental `v0.1.0`.
